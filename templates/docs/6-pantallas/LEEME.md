# 6 · Las pantallas

Un diagrama por bloque (`B-001-...md`) con el camino que recorre una persona entre las pantallas del producto, incluidos los caminos que salen mal.

**Cómo se llaman en la industria:** **user flows** o flujos de navegación. Están escritos en Mermaid, que GitHub y muchos editores dibujan solos.

**Qué hacer con esto:** dáselo a quien diseñe las pantallas. Le ahorra la mitad de las preguntas, sobre todo las de *"¿y qué pasa si falla?"*.

**Esta carpeta es opcional.** El producto se puede construir perfectamente sin ella. Ayuda cuando el producto tiene muchas pantallas o muchos caminos alternativos.

**Regla importante:** ningún paso de estos diagramas está inventado. Cada flecha corresponde a un criterio de aceptación que ya escribiste en `docs/3-tareas/`.
