# CLAUDE.md — docs/4-lista-de-trabajo/

Reglas locales para esta carpeta. El método completo está en `METODO.md` §6.

## Archivos

`lista.md` — una tabla con todas las tareas del proyecto.

## Reglas clave

1. **El orden de las filas ES la priorización vigente.** Aquí no se inventa prioridad: eso lo decide `decidir-que-va-primero`.
2. **Columnas obligatorias**: `#, ID, Título, Bloque, Prioridad, Complejidad, Estado, Criterios, Notas`.
3. **Toda tarea aparece**, incluidas las que están en borrador (marcadas como tales).
4. **Al regenerar, se preserva el orden previo.** Las tareas nuevas se añaden al final con prioridad `?`.

## Skill y revisor

- Skill: `lista-de-trabajo`
- Revisor: `revisor-de-conexiones`

El detalle de cada tarea (en `docs/3-tareas/`), las sesiones de priorización (en `docs/5-que-va-primero/`).
